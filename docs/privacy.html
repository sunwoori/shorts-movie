PRIVACY POLICY

개인정보처리방침

시행일: 2026년 11월 27일

1. 이 도구의 성격

쇼츠 업로더는 운영자 본인의 유튜브 채널에 영상을 올리기 위한 개인용 도구입니다. 운영자 외의 사람이 가입하거나 로그인해서 쓰는 서비스가 아닙니다.

2. 수집하는 정보

다른 사람의 개인정보를 수집하지 않습니다. 이 웹페이지는 방문 기록을 따로 수집하거나 분석 도구를 쓰지 않습니다.

3. 구글 계정 데이터의 사용

  • YouTube Data API의 동영상 업로드 권한(youtube.upload)만 요청합니다.
  • 이 권한은 운영자 본인의 채널에 영상을 업로드하는 데에만 사용합니다.
  • 채널의 시청 기록, 댓글, 구독자 정보 등 다른 데이터는 읽거나 저장하지 않습니다.
  • 구글 계정 데이터를 제3자에게 제공하거나 판매하지 않으며, 광고에 사용하지 않습니다.

4. 인증 정보의 보관

업로드에 필요한 인증 값은 운영자의 GitHub 저장소 Secrets에 암호화되어 보관되며, 공개 저장소의 파일이나 이 웹페이지에는 포함되지 않습니다.

5. 권한 철회

운영자는 구글 계정의 보안 설정(서드 파티 앱 액세스)에서 언제든지 이 도구의 접근 권한을 삭제할 수 있습니다.

6. 문의

GitHub 저장소의 Issues로 연락할 수 있습니다.
