SHORTS UPLOADER

쇼츠 업로더

운영자 본인의 유튜브 채널에 직접 만든 짧은 영상을 올리기 위한 개인용 도구입니다.

하는 일

  • 운영자가 만든 세로형 카드뉴스 영상을 운영자 본인의 유튜브 채널에 업로드합니다.
  • 업로드는 운영자가 게시를 요청한 영상에 한해 실행됩니다.

쓰는 권한

YouTube Data API의 동영상 업로드 권한(youtube.upload)만 사용합니다. 다른 사람의 계정에는 접근하지 않으며, 일반 사용자에게 제공되는 서비스가 아닙니다.
